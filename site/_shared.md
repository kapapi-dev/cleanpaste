# Site source

These four pages are published from the separate `cleanpaste-site` repository, which
GitHub Pages serves at <https://maxtop9843-byte.github.io/cleanpaste-site/>.

They live here too so that the product and the pages that describe it change in the
same commit. `PRIVACY.md` in the repository root and `privacy.html` here must always
say the same thing.

The `google-site-verification` meta tag on every page verifies the exact URL prefix in
Search Console. Google's OAuth brand verification checks the home page URL is
registered to the developer, and inheriting verification from the domain root was not
enough for it on the previous project. Do not remove the tag.
